# Stacking Items – Simulador (Primer Ciclo)

## Integrantes
- Nicolás Prieto  
- Sebastián Peña  

## Descripción del Proyecto

Este proyecto corresponde al primer ciclo del curso Desarrollo Orientado por Objetos (DOPO-POOB) 2026-1 en la Escuela Colombiana de Ingeniería.

Se desarrolló un simulador inspirado en el Problem J – Stacking Cups del ICPC.

En esta etapa no se resuelve el problema algorítmico, únicamente se construye el simulador utilizando BlueJ y el paquete shapes.

## Funcionalidades Implementadas

- Crear torre
- Agregar y eliminar tazas
- Agregar y eliminar tapas
- Ordenar elementos
- Invertir orden
- Consultar altura
- Consultar información
- Modo visible e invisible
- Finalizar simulador

## Tecnologías

- Java 21 (BlueJ 5.4.1)
- Astah 10.0.0
- Git & GitHub
